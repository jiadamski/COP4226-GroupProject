# COP4226-GroupProject
Using the partially developed Project database BikeStore.mdfDownload BikeStore.mdf, the team will complete the shopping cart functionality and each member will complete an individual component for user login, maintenance (customer, product), sale reporting or error log. Assume that this application is used to purchase products from a Bike Store.  The customer comes to the store and purchases products. The employee enters the products and quantities in the application and produces an invoice/receipt for the customer.
